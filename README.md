# PID Test

本次任务使用的主要硬件有：DJI 3508 电机， DJI C620 电调（拨码 ID = 1）, 达妙 DM-MC-Board02 开发板（STM32H723VGT6），ST-Link。

速度环和角度环都写了，默认是速度环。在 ai 帮助下调整了不少细节，让代码更周密。

## 关于 BSP

主要参考老代码里的 BSP ，从中选取了需要的部分，做了一些适配（参考了 deepseek 的检查与建议），例如：

- 没有原样引用 `FreeRTOS.h`、`queue.h`，因为是裸机运行；
- 我先前写的 CAN 收发和反馈解析用的不是这套 BSP 的 `Motor.c` 和 `DJI_Motor.c`，方便起见，这部分在 `main.c` 里重写了。

## 模式切换

通过改 `main.c` 里的 `g_ctrl_mode` 可在不同模式切换：

| 值 | 模式 | 目标变量 |
|---|---|---|
| 0 | 开环 （用于调试） | — |
| 1 | 速度环 | `g_target_rpm`，转子 rpm |
| 2 | 角度环 | `g_target_deg`，输出轴角度数 |

几个调试变量都加了 `volatile`，调试时可以直接改，就不用重新烧录了。（d老师教的）
